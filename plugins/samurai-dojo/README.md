# Samurai Dojo

The samurai hunts Codex and Gemini aliens during search calls, meditates while reading, cuts bamboo during edits, strikes training dummies during tests, and duels a purple rival during other work. Idle time sharpens the sword; completion celebrates. Victories persist locally.

```sh
claude plugin marketplace add theonly1me/claude-code-mods
claude plugin install samurai-dojo@claude-code-mods
```

Register the marketplace once. Run `/reload-plugins` in an open session after installing. Requires Claude Code 2.1.287 or later; no build step or runtime dependencies.

Bare `/dojo` preserves the original toggle. `/dojo show` explicitly selects it. Search combat preserves the original dojo artwork and simulation; other activities use the same samurai art with new scenery.

Use `/dojo show`, `hide`, `compact`, or `expanded`. Starts hidden and opens compact with at most six animation rows. Expanded mode is capped at twelve. Click the scene buttons to switch, or Hide to close it. Question dialogs take priority. Desktop uses colored text pixels.
